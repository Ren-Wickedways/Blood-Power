# Blood-Power
Blood &amp; Power is a text game in the terminal baste of Macbeth 

#**How to play**
How to Play:
YOUR MAIN GOAL: How much power can you gain before level 10?
*************************************
1. Move: Move to the next room. Each room contains loot, and every 5 rooms there is an enemy & every 10 there is a Boss Battle. Explore different rooms to find items and power-ups that can help you in combat. (Right now the weapons only affect non-boss combat, but in the future they will have more uses!)
*************************************
2. Looting: In each room, type 'Loot' to search for items. The type of room you are in will affect the loot you find. You can only loot once per room, so choose wisely! (Right now there are only 4 items, but more will be added later with more functionality.)
*************************************
3. Fight: Engage in combat with enemies you encounter. Defeat them to gain power and progress.
*************************************
4. Inventory: View, use, or drop items you have collected. Some items can be used in combat for advantages. Without a weapon you will be killed. Every 5 rooms there is an enemy, and every 10 there is a Boss Battle. (There is only one boss battle right now.)
*************************************
5. Items: There are 2 weapons in the beta version – the potion and the sword. The sword is more powerful than the potion, with attacks that depend on how much damage the enemy deals. The potion is very weak and will only chip away at enemy health, so it’s unlikely to kill them. REMEMBER TO EQUIP AN ITEM USING 'Inv' → 'Use' → <item name>; otherwise you will die in combat. To drop an item, use the 'drop' command in the inventory menu; once dropped you can’t get it back.
*************************************
6. Notes: There are some bugs – the terminal sometimes goes blank for 2–3 seconds, and dropping items can duplicate them.
*************************************
